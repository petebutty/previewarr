# Previewarr (preview)

**Previewarr** is a preview of the next [Viewarr](https://github.com/petebutty/viewarr) interface for Android TV: a home screen of tiles and rows on Viewarr's live TV, guide, films and shows, music and sports, with one simple Settings page.

This repository only holds Previewarr's **downloads**. The code, the issues and the full guide live in the main Viewarr repository:

- **Guide:** [Previewarr guide](https://github.com/petebutty/viewarr/blob/main/docs/PREVIEWARR.md)
- **Code and issues:** [petebutty/viewarr](https://github.com/petebutty/viewarr)

## Install

1. On your TV, install the **Downloader** app (by AFTVnews).
2. Enter the code **6733457**, or this link (both always get the newest version):

   `https://github.com/petebutty/previewarr/releases/latest/download/previewarr.apk`

3. Allow Downloader to install apps when asked, then open **Previewarr**.

It installs alongside Viewarr (you don't need both). It's a preview, so things will change; Viewarr carries on as the main app.

Previewarr doesn't provide any content: it plays only what your own servers and accounts give it.
